# Tab Groups Pro

Organize your VS Code open files into named, color-coded groups — just like Chrome tab groups.

## Features

- **Create named groups** with a custom color (🔴🟠🟡🟢🔵🟣🩷⚫)
- **Drag files between groups** directly in the sidebar
- **Drag files from the Explorer** into a group
- **Open / Close all** files in a group at once
- **Snapshot open tabs** — one-click to group all currently open files
- **Persistent across sessions** — groups are saved per workspace
- **Live "open" badge** — see how many files in each group are currently open

## Usage

1. Click the **Tab Groups** icon in the Activity Bar (grid icon)
2. Use **+** to create a new group, or use the **Group All Open Tabs** button
3. Right-click a group to add the active file, open/close all, change color, rename, or delete
4. Drag files between groups in the sidebar
5. Drag files from the Explorer into a group

## Keyboard / Command Palette

All commands are available via `Ctrl+Shift+P` → search "Tab Groups".
